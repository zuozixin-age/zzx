# AETHER-01 · eVTOL 飞行汽车展示网站

视频主导的单页展示站：网站本身不做 3D 动画，全部画面来自 AI 生成视频拆出的帧序列。

- **主线**：3000 帧（1920×1080 WebP）由一个全局滚动进度统一驱动，Canvas 双向擦洗，滚轮 / 触摸 / 拖拽带惯性，正反向同等顺滑。
- **支线**：3 个锚点帧区间可点击进入支线短片（旋翼近景 / 绕机飞行 / 站点降落），播放结束精确返回点击时的主线帧，进度不变。
- **文字与 UI 是真实 DOM**，与画面层分离；参数页的性能数字全部为「待核实」占位，未编造。

## 怎么看

- 启用 GitHub Pages 后访问 `/site/` 即可；或在仓库根目录起任意静态服务器（如 `python3 -m http.server`），打开 `site/index.html`。
- 注意：`site/` 与 `aether-01/` 必须保持同级目录（站点按相对路径 `../aether-01/` 读取素材）。

## 结构

- `site/` — 站点代码（原生 HTML/CSS/JS，GSAP / ScrollTrigger / Lenis 已本地自带，零构建、零 CDN）
- `aether-01/` — 素材与数据：`main/` 主线十段、`branches/` 支线三段、`anchors/` 锚点帧、`hotspots/` 热点坐标、`content/` 章节与参数数据、`references/` 飞机设定与分镜、`qc/` 质检报告
- 二进制素材（帧序列等约 7,300 个文件）由 `.github/workflows/import-assets.yml` 自动下载解压并提交入仓，`assets-import/urls.txt` 为其下载清单
