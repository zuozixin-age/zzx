# AETHER-01 · eVTOL 飞行汽车概念展示网站

《飞行汽车技术基础》课程作业。本站以一台原创 eVTOL（电动垂直起降飞行器）概念机 AETHER-01 为对象，用一个可滚动浏览的网页，展示它的整体构型、关键技术与运营构想，并对技术可行性、应用场景与市场可行性作初步分析。

## 访问方式

- 在线访问：开启 GitHub Pages 后，从仓库根目录 `index.html` 进入（会自动跳转到展示站）。
- 本地访问：在仓库根目录起任意静态服务器（如 `python3 -m http.server`），浏览器打开 `index.html` 即可。注意 `site/` 与 `aether-01/` 两个目录必须保持同级。

## 内容结构

网站共六章，滚动页面即依次浏览：

1. **序幕 · 机库显形**——概念机整体亮相
2. **亮相 · 绕机环视**——整体构型：高翼布局、对称 V 型尾翼、六组倾转旋翼（主翼四组、V 尾两组，每组五叶），珍珠白流线型机身与深石墨灰推进舱
3. **细节 · 旋翼倾转**——关键技术：推进舱绕固定铰接轴倾转，桨盘在升力构型与巡航推力构型之间转换；含倾转机构工程难点的说明
4. **起飞 · 穿城飞行**——垂直起飞、倾转过渡到固定翼巡航的完整过程
5. **站点 · 降落**——垂直起降站的进近与降落，以及站点规划需统筹的荷载、净空、充电、安全与噪声等问题
6. **参数与收尾**——构型参数表，以及技术可行性、应用与市场可行性的分析小结

第 3、4、5 章设有可点击的热点，点击后进入近景支线画面，播放结束自动回到主线原位置。

## 技术实现

- 纯静态站点，原生 HTML / CSS / JavaScript 编写，无构建步骤，不依赖任何外部服务，开箱即跑。
- 画面层采用视频帧序列呈现：滚动进度统一映射到帧号，由 Canvas 双向绘制，支持滚轮、触摸与拖拽，正反向滚动同等顺滑；文字、参数与导航为真实页面内容，与画面层分离。
- 全站素材 3,630 帧（1920×1080），含主线十段、支线三段与三处锚点帧，完整性已经全量校验。

## 目录结构

- `index.html`——仓库根入口（跳转页）
- `site/`——站点代码（页面、样式、脚本、自带的前端库）
- `aether-01/`——素材与数据：`main/` 主线帧序列、`branches/` 支线帧序列、`anchors/` 锚点帧、`hotspots/` 热点坐标、`content/` 章节文案与参数数据、`references/` 构型设定与分镜文件、`qc/` 质检报告
- `assets-import/`、`.github/workflows/`——素材自动导入仓库的流程文件

## 说明

AETHER-01 为原创概念设计，不对应任何真实产品。构型参数为本设计的设计冻结值；性能、认证与商业类参数属于需要查证公开来源后才能填写的内容，站内统一标注「待核实」，未作任何编造。
