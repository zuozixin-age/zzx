# AETHER-01 关键帧构图草案（Shot Plan）v1

- 配套母版：`AETHER-01-BIBLE-v1`（aircraft-bible.md + 9 张母版图 + 2 张光照板）
- 依据：PDF01 六章结构与进度带 + PDF02 分镜表（时长/帧数/接缝/锚点）
- 规格统一：16:9、1920×1080、30 FPS；主线 M01–M10 共 100 s / 3000 帧；支线 B01–B03 共 21 s / 630 帧
- 全局帧号 = 主线累计帧（M01 起 0）：M01 0–239 / M02 240–539 / M03 540–809 / M04 810–1049 / M05 1050–1349 / M06 1350–1649 / M07 1650–2009 / M08 2010–2309 / M09 2310–2639 / M10 2640–2999
- 锚点（离线将原锚帧连续重复 30 帧构成可点击静止区间；支线第 0 帧用锚帧原图逐像素复制）：
  - **A-ROT**：M05 局部 180–209 帧（全局 1230–1259），旋翼倾转近景静止帧 → 支线 B01
  - **A-FLY**：M07 局部 240–269 帧（全局 1890–1919），巡航三-quarter 开阔构图 → 支线 B02
  - **A-STN**：M08 局部 210–239 帧（全局 2220–2249），站点全貌清晰构图 → 支线 B03

## 第 01 章 · 序幕 机库显形（进度 0–8%）

### M01 · 机库显形（8 s / 240 帧 / 蓝调）
- 起始构图：近全黑机库，地面微反射，画面仅见顶部蓝色灯带与微弱轮廓光；镜头位于机头左前方低位、远距。
- 结束构图：缓推到位，机头左前 3/4 轮廓被冷蓝光勾出（对应 master-front45 的机头局部），定格稳定 ≥15 帧供接续。
- 接缝：M01 尾帧构图 = M02 首帧构图（同机位继续后移），以光照渐亮代替切点。
- 锚点：无。

## 第 02 章 · 亮相 绕机环视（8–27%）

### M02 · 整机显现（10 s / 300 帧 / 蓝调）
- 起始构图：承接 M01 尾帧的机头左前特写向构图。
- 结束构图：摄影机后移+缓升完成，整机左前 45° 宽画幅定格（= master-front45 构图），六组旋翼全部可读。
- 接缝：首帧与 M01 尾帧同构图（光照匹配渐亮）；尾帧构图 = M03 环绕起点。
- 锚点：无。

### M03 · 半环绕（9 s / 270 帧 / 蓝调）
- 起始构图：侧面全机（承接 M02 a2 尾帧；M02 采用版尾帧为侧面而非左前 45°，故 M03 改为由侧面起绕、向后侧半环绕；2026-11-20 第二批 b2 即按此生成，参考图为 M02 尾帧原图）。
- 结束构图：环绕约 180° 至机身后侧（对应 master-rear45 视角区），主翼逐渐充满画面形成物理擦镜。
- 接缝：尾端机翼遮镜（wipe）→ M04 自翼面滑轨开始，遮挡内完成机位切换。
- 锚点：无。

## 第 03 章 · 细节 旋翼倾转（27–45%）

### M04 · 沿翼靠近推进舱（8 s / 240 帧 / 蓝调）
- 起始构图：机翼上表面近景滑轨（承接 M03 擦镜），翼面接缝与珍珠白材质充满画面下半。
- 结束构图：滑行至左翼一组推进舱中近景（对应 master-rotor 构图区），画面留出干净负空间供 DOM 热点叠加。
- 接缝：同向滑轨运动连续进入；尾帧构图 = M05 固定近景起点。
- 锚点：无。

### M05 · 旋翼倾转与停顿（10 s / 300 帧 / 蓝调→末段透出金色光）
- 起始构图：固定近景，左翼推进舱居中，桨盘处于垂直升力构型。
- 中段：推进舱绕固定铰接轴刚体倾转向前飞构型（全程舱体外形/连接点不变）；**局部 180–209 帧为完全静止的锚帧区间**（倾转中途的清晰近景构图，桨叶 5 叶可数）。
- 结束构图：摄影机轻微抬升，机库开口的金色光线渐满画面形成明亮遮挡。
- 接缝：首帧承接 M04 尾帧；尾端金色光遮挡 → M06 金色时刻户外（光照 A→B 在遮挡中完成切换）。
- 锚点：**A-ROT（局部 180–209 / 全局 1230–1259）→ B01 入口**。

### B01 · 支线 旋翼近距观察（6 s / 180 帧 / 蓝调）
- 起始构图：第 0 帧 = A-ROT 锚帧原图（逐像素一致，非重新生成近似帧）。
- 内容：摄影机向推进舱推进并小幅绕铰接区，观察刚体倾转的外部结构；只展示合理外部接缝，不发明内部机构。
- 结束/回切：推进舱暗部表面充满画面（暗部遮挡）→ 返回用户点击时保存的 M05 精确帧号继续播放。
- 接缝方式：入口像素级对齐；出口强遮挡回切（须实际回切观看验收，不得声称数学无缝）。

## 第 04 章 · 起飞 穿城飞行（45–67%）

### M06 · 垂直升起（10 s / 300 帧 / 金色）
- 起始构图：低机位 3/4，飞机静止于现代起降坪，六组旋翼垂直升力构型（参照 master-hover 的构型定义；注意母版图桨盘姿态已知问题，生成时必须纠正为桨盘水平）。
- 结束构图：垂直升起→稳定悬停→开始前倾过渡，摄影机跟升后拉；薄云掠过镜头遮挡。
- 接缝：首帧承接 M05 金色光遮挡散开；尾端云层掠镜 → M07 同向跟飞。
- 锚点：无。

### M07 · 城市穿行（12 s / 360 帧 / 金色）
- 起始构图：云层散开，同向航拍跟飞开始，飞机巡航构型（= master-cruise），滨海城市、水面、桥梁在远景。
- 中段：**局部 240–269 帧为静止锚帧区间**——机身清晰、背景开阔的三-quarter 巡航构图，与建筑保持安全间距。
- 结束构图：保持同向飞行延续，构图微收，为 M08 后侧跟拍留出方向一致性。
- 接缝：首端云遮挡散开；尾帧运动方向 = M08 跟拍方向（同向运动接缝）。
- 锚点：**A-FLY（局部 240–269 / 全局 1890–1919）→ B02 入口**。

### B02 · 支线 飞机 360° 绕飞（8 s / 240 帧 / 金色）
- 起始构图：第 0 帧 = A-FLY 锚帧原图（逐像素一致）。
- 内容：飞机保持航向与巡航构型不自转，摄影机完成一次完整 360° 环绕（前→侧→后→另一侧），城市视差连续。
- 结束/回切：飞机近距离掠镜形成自然甩镜运动模糊 → 返回点击时保存的 M07 精确帧号。
- 接缝方式：入口像素级对齐；出口甩镜遮挡回切（实际观看验收）。

## 第 05 章 · 站点 降落（67–88%）

### M08 · 接近屋顶起降点（10 s / 300 帧 / 金色）
- 起始构图：侧后方跟拍，飞机向屋顶站点接近（站点为真实尺度的简洁屋顶设施，禁止悬浮平台类虚构结构；停机坪无可读标记）。
- 中段：摄影机缓升至清晰俯视，**局部 210–239 帧为静止锚帧区间**——站点全貌完整可见、飞机与站点空间关系清晰。
- 结束构图：屋顶建筑结构横过画面形成遮挡。
- 接缝：首帧承接 M07 同向运动；尾端建筑遮挡 → M09 侧前方降落机位。
- 锚点：**A-STN（局部 210–239 / 全局 2220–2249）→ B03 入口**。

### M09 · 平稳垂直降落（11 s / 330 帧 / 金色）
- 起始构图：侧前方视角，飞机减速接近站点上方，推进舱转入垂直升力构型。
- 结束构图：短暂悬停→缓慢下降→起落架接地→飞机停稳，摄影机随之放缓并稳定（尾帧静止构图 = M10 起点）。
- 接缝：首端承接 M08 建筑遮挡；尾帧与 M10 首帧同构图（停稳整机）。
- 锚点：无。

### B03 · 支线 站点降落特写（7 s / 210 帧 / 金色）
- 起始构图：第 0 帧 = A-STN 锚帧原图（逐像素一致）。
- 内容：摄影机向站点推进并转至飞机侧前方近景，观察悬停下降、接地与重量感（阴影、起落架压缩合理），不发明特写工程细节。
- 结束/回切：机身近距离充满画面（机身遮挡）→ 返回点击时保存的 M08 精确帧号。
- 接缝方式：入口像素级对齐；出口机身遮挡回切（实际观看验收）。

## 第 06 章 · 参数与收尾（88–100%）

### M10 · 参数背景氛围（12 s / 360 帧 / 金色→蓝调）
- 起始构图：承接 M09 尾帧，停稳的飞机位于屋顶站点，侧前方中远景。
- 结束构图：极缓慢后撤至宽景，飞机+站点+远处滨海城市全景；画面右侧留大面积干净负空间供 DOM 参数/标题（视频内不绘制任何文字图形）；光线由金色时刻自然渐变至蓝调暮色收尾。
- 接缝：首帧与 M09 尾帧同构图；全片终帧（定格/氛围循环点由 PDF03/04 决定）。
- 锚点：无。
